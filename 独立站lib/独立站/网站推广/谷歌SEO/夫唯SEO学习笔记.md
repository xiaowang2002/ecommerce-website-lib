## 二、域名常见问题

**域名选择三原则：**

1. 用 `.com`
2. 包含核心关键词，例如 `trikebike.com`、`worldofwatches.com`
3. 用短句组合，例如 `anytimeoffitness.com`、`bikemag.com`、`worldofwatches.com`

**手机配件怎么定域名？** 有钢化膜、手机壳、数据线，应该怎么定域名？不要做「手机配件」的域名——用户不会直接搜「手机配件」。建议做三个网站，例如主要卖钢化膜（当然也可以顺带卖手机壳和数据线）。

**其他注意事项：**

- `cn` 域名会被谷歌歧视
- 老域名看情况买（确实能给独立站初期带来一些流量，但要小心别买到灰产的）
- 小众后缀不要选
- 品牌 + 品类问题：做引流直接放类目做域名，做品牌用品牌域名，不要用「品牌+品类」作为域名，例如小米中华线手机
- 注册不到想要的域名，可以带斜杠或数字，但不要两个都带，太 Low 了
- 域名要跟着用户会搜的核心关键词来定，例如做亲子游业务，域名上要选「桂林游」这种用户会用的核心关键词
- 域名不要包含大品牌单词（iPhone、LV），权重过高容易被收

## 三、选 WordPress 还是 Shopify

**B2B 企业官网**：选 WordPress 或 Joomla，后者更高级，可以看看对比博客。

**B2C 商城**：选 WordPress + WooCommerce，或 Shopify。

- 前者需要一定程序基础，但擅长承载文章、做 SEO
- 后者更便利，但 SEO 有一定限制

**总结**：流量付费选 Shopify；SEO 用 WordPress，流量起来后用插件或 Shopify 嵌入。

## 四、空间服务器选择：独立服务器还是虚拟主机

- **独立服务器**：适合大型网站、特殊应用、对稳定性要求高的，需要技术人员

- 美国虚拟主机商：Bluehost、SiteGround、JustHost、HostGator
- 美国域名商：Namecheap、GoDaddy、Domain.com

## 五、网站定位

**定位是 Google SEO 成功的捷径：网站要定位某一个细分领域。**

**案例分析：**

- 中文案例：小提琴作坊（搜「莫扎特 小提琴」等能搜到）、花百科（搜「水仙花和百合的区别」「怎么养百合」等能搜到）
- 英文案例：`celebheight.com`（搜「姚明 身高」能搜到）、`celebritynetworth.com`（搜「马云 身价」能搜到）
- 电商案例：`sockshop.co.uk`（搜「男生 袜子」「女生袜子」「黑 袜子」等能搜到）

**定位理念：**

1. **心智定位**（通过广告打造心智认知）：第一品牌、质量、附加值；性价比高、适合群体；售后保障、物流等
2. **搜索定位**（让搜索引擎理解从而推荐）：网站长尾词所包含的词；一个特定兴趣人群、行业人群

**定位分析：**

- 定位家电 VS 定位空调
- 定位服装 VS 定位鞋子、包、衬衫
- 定位古典音乐 VS 定位小提琴、钢琴、吉他
- 定位名人 VS 定位名人身高、名人身价
- 定位宠物 VS 定位猫猫、狗狗（还可以细分品种）

**结论：所有长尾词都会包含后者（细分），而不是前者（大类）。**

## 六、ABC 拓词法确定目标关键词

**WHAT（是什么）：**

用来给网站确定目标关键词的一套科学方法。

流程：确定 ABC 结构的主词（三个词），由主词拓展出多个词，共同构成目标关键词（寻找它逻辑上的同义词，可以一小词一小词地替换）。

- 中文例子：办公室绿植出租、会场鲜花租摆、酒店盆栽租赁
- 英文例子：Google SEO Guide、Search engine optimization Fundamentals、ways to improve site's Ranking

**WHY（为什么）：**

- 给网站首页设置尽可能多的关键词，如中文例子中的 27 个易词和众多难词（两两组合替换）
- 满足梯度设置的原理（给网站首页设置关键词，关键词包含难的和易的）：办公室绿植出租是易的，绿植出租是中等，绿植是难的，还有会场鲜花租摆、酒店盆栽租赁

**HOW（怎么做）：**

1. 确定关键词：搜索结果出现比较频繁的词（被认为是用户的需求），确定 ABC 结构的核心关键词
2. 拓展关键词：用核心关键词拓展出多个关键词，可以参考上面的中英文案例
3. 书写标题：最核心的词放前面，如英文案例中的 Google SEO Guide；尽量不出现重复的词

**FAQ：**

- 标题目标关键词的个数：可见的三个，其中包含多个自由组合的词
- 是否考虑搜索量：主词考虑搜索量（Google SEO Guide），次词只考虑行业需求
- 标题写法、位置摆放：见下一小节

**总结：** 确定业务（绿植出租）—(ABC 拓词法)→ 办公室绿植出租 → 拓展出次目标关键词

## 十三、用 Rank Math 优化文章发布流程

1. 点文章的 edit snippet
2. **Title** 就是 SEO 标题：默认取文章标题，但标题太长或没包含核心关键词，就取核心词做 SEO 标题
3. **Permalink（URL）**：标题里最核心的部分，用 `-` 隔开
4. **Description**：标题里想要出现的核心关键词
5. 以上 1、2、3、4 可以用插件的 Generate with AI 生成
6. **Focus keyword**：同时出现在 SEO 标题、URL（permalink）、Description 中的关键词
7. Basic SEO、Additional、Title Readability 等，最后评分在 SEO 中超过 75 就行

## 三十、链接（Links）：内链与外链

**What（是什么）：**

- 分类：内链、外链
- 格式：
  - 可被抓取：`<a href="http://example.com">`、`<a href="/relative/path/file">`
  - 不可被抓取：`<a routerLink="some/path">`、`<span href="https://example.com">`、`<a onclick="goto('http://example.com')">`

**Why（为什么）**：搜索引擎通过链接传递权重、获取信息（锚文本、alt 属性）

**How（怎么做）：**

- 内链：一个普通页面上放 30 个以上内链
- 外链：友情链接、留言链接（选择相近行业去留言，否则会被当垃圾）、论坛链接（同上）、投稿版权出处（记得标明出处）

## 三十九、网页未被编入索引的原因

| 原因           | 说明                                           |
| ------------ | -------------------------------------------- |
| robots.txt   | 被 robots.txt 屏蔽，一般是自己主动要求屏蔽而写的文件             |
| Canonical    | ①重复网页，未选定规范网页，加 Canonical 标签；②备用网页（有适当的规范标记） |
| 重定向          | 网页会自动重定向，检查确实是自己做的重定向就没问题                    |
| 4XX / 5XX 错误 | 未找到 404、软 404、禁止访问（403）、服务器错误（5XX）           |

补充：如果是 404 错误，去 GSC「删除」把它删掉。

**关于 noindex：**
   1、noindex  表示在标签上注明不让收录（主动拒绝）
   2、自行决定是否去除，一般是在作者页面，没有内容的分类页面，Tag页面。Rank math SEO插件默认不收录，建议遵循。也可以在插件里改
   3、去除方法，插件里关闭

## 四十三、AdSense 选行业与广告审核

**如何选择一个行业：**

1. 通过 Google AdSense 官网行业预估收入来判断
2. 通过某一个行业关键词来搜索
3. 分析网站流量：aitdk.com、similarweb.com
4. 找到相关中文的内容源

**大体思路：** 做大型网站的某一个细分，如「心理·老人」「心理·小孩」「宠物·猫」「宠物·狗」。做某一个兴趣人群，可以根据 Reddit 某一个兴趣小组做网站。直接 AI 改写 + 翻译一个内容源。

**广告审核（屏蔽广告）：**

- 违法违规的广告
- 相关性太差的广告
- 不希望出现的其他广告

操作：去 Google AdSense「广告审核中心」，把某个广告屏蔽掉。

## 四十四、独立站入境旅游项目介绍

**接单整体流程：**

```
询盘 → 客服定制需求并向客户确认 → 定金 → 服务 → 收款
```

**主要盈利点：** 导游服务、车队服务。

**建议做的内容方向：** 线路攻略类、景区政策类、当地美食类。

**推荐国家和语种：** 东南亚、海外华侨华人、日韩（简单、投入产出高）；也可以做英语、西班牙语等，只不过 ROI 低一点。

**推荐城市、景点：** 西安、成都、重庆（文化旅游）；北上广深（偏商业）。主要看哪些城市、景点外国人多。

**合作模式及流程：** 负责询盘接收、售前、销售；服务、售后交给别人；最后按比例分成。
